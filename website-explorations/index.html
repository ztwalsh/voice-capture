ztwalsh.com, through a tube

Five layouts of the same content, each rendered through a WebGL CRT shader. Every one flips between black and white with the invert control on the page.

  1. 01BroadcastThe current site's structure, monochrome, through the tube. The control.darklight
  2. 02IndexA teletext page: header strip, page number, live clock, numbered rows.darklight
  3. 03SignalThe page types itself in, one line at a time, behind a blinking block cursor.darklight
  4. 04ChannelA TV on-screen menu. Arrow keys or hover move the highlight; the caption follows.darklight
  5. 05SetThe page inside a physical television: bezel, glass, brand plate, power light.darklight

On any page press T for the shader tuning panel. Add ?crt=off to see the plain DOM underneath.
