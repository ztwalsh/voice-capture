MoveThink landing page options

Four directions, all standalone HTML with real product copy. Serve this folder (python3 -m http.server) rather than opening files directly so the fonts load.

  1. A · AuroraClosest to the reference: warm canvas, centred headline, a gradient-mesh showcase with icon tabs that recolour as you scroll, then a four-step section.
  2. B · StudioDark, built from design.md's own tokens. The hero is a working hold-to-talk demo (hold Space); features are a measured spec sheet, not cards.
  3. C · PaperThe page is written as a day file. Ruled paper, a wide grotesk display face, and the Markdown file itself as the hero object.
  4. D · KineticElectric indigo hero where dictated sentences type themselves into Slack, Xcode, Notes and Messages, then a bento grid of features.
